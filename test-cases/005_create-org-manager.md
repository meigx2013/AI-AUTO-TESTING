# 用例名称： 创建组织管理员用户
本用例适用于超级管理员创建组织管理员用户
## 操作步骤
1. 用户进入 ASDM管理后台 首页
2. 点击左下角 [平台级设置] 按钮
3. 右侧工作区打开 平台级设置 页面
4. 点击 [用户] Tab页签
5. 点击 [+创建用户] 按钮
6. [新建用户]信息录入
   新用户邮箱: test01@asdm.ai   
   初始密码: admin@2026
   姓: 测试
   名: 一   
7. 点击 [新增角色映射]
   第一个下拉框选择 [组织管理员]
   第二个下拉框选择 [测试组织01]
8. 点击 [创建用户] 按钮
9. 用户列表中增加一条组织管理员用户记录
## 预期结果
1. [测试组织01]中新增1条组织管理员用户记录
## 前置条件
1. 用户已完成系统登录
2. 已创建组织 "测试组织01"
