### 操作指引

请使用 Chrome Dev Tools Recorder 执行以下操作以生成录制脚本：

1. **补充录制 - <场景名>**
   - 在 Chrome 中导航到目标页面
   - 打开 DevTools → Recorder 面板，新建录制并开始录制
   - 执行完整操作流程（可加入断言步骤）
   - 停止录制后导出为 json
   - 将录制结果保存到 `recordings/<模块>/<模块>-<场景简称>.json`

2. **新建录制 - <场景名>**
   - 同上步骤

> 录制完成后，请重新运行本指令以继续生成测试脚本。
