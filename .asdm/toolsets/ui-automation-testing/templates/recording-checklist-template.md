# 录制清单模板

以下为 `recording-checklist.md` 的原子操作录制指引模板和录制补完检查表模板。

---

## 原子操作录制指引模板（5.2 节）

按"产品功能特性 → 原子操作"组织输出，每个原子操作是独立可录制的单元，供人工灵活录制。步骤需**完整、可执行**（面向人工，不使用引用占位）：

```markdown
### 🧩 产品功能特性：<功能名称>

#### ⚛ 原子操作 <N>：<操作名称>

**功能归属**：<功能归属>
**前置状态**：<前置状态>
**保存为**：`recordings/<模块>/<文件名>.json`

| 序号 | 操作 | 目标元素 | 预期反馈 | 步骤类型 |
|------|------|---------|---------|---------|
| 1 | <操作> | <目标元素> | <预期> | 🔴 必须 |
| 2 | <操作> | <目标元素> | <预期> | 🟡 建议 |
| ... | ... | ... | ... | ... |

**可添加断言**：<断言建议>
```

### 工具操作指引

1. 打开 Chrome 浏览器，导航到测试页面
2. 按 `F12` 打开 DevTools → **Recorder** 面板
3. 点击 **"Create a new recording"** → 命名：`<录制脚本名>`
4. 点击 **"Start recording"** 开始录制
5. 按上表顺序执行操作
6. 可点击 **"Add assertion"** 添加断言（验证文本/元素可见性）
7. 操作完成后点击 **"Stop recording"**
8. 点击 **"Export"** → 选择 **"Export as JSON"**
9. 保存到：`<保存为路径>`

## 录制补完检查表模板（5.3 节）

```markdown
## ✅ 录制补完检查表

### 录制脚本补完状态

- [ ] `recordings/<模块>/<文件>.json` — <描述>

### 确认项

- [ ] 所有 🔴 必须录制的步骤都已录制
- [ ] 所有 🟡 建议录制的步骤已尽量覆盖
- [ ] 每个录制脚本包含必要的断言
- [ ] 录制文件已保存到 `recordings/<模块>/` 目录下

> **完成以上检查后**，请运行 `/asdm-ui-test-design-generate` 以基于录制脚本生成自动化测试脚本。
```
