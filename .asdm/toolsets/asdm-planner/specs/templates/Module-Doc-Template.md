## 附录：模板使用说明

### A. 文档命名与存放

**文件命名格式**：
```
_index.md                           # 模块主文档（必需）
{sub-module-name}.md                # 子模块文档（可选）
images/{module-abbr}-{feature}.png  # 截图文件
```

**存放路径**：
```
asdm-docs/public/docs/zh-cn/content/platform/modules/{module-name}/
├── _index.md
├── images/
│   └── ...
├── {sub-module-1}.md
└── {sub-module-2}.md
```

### B. 章节组织指南

**章节划分原则**：

1. **概述章节**（第1章）：必须包含模块定义、核心功能列表、功能架构
2. **功能章节**（第2章起）：按功能特性组织，每个大功能点为一个章节
3. **章节深度**：通常到三级（1.1.1），避免超过四级

**功能章节划分方式**（按需选择）：

| 划分方式 | 适用场景 | 示例 |
|----------|----------|------|
| 按用户操作流程 | 功能间有明确先后顺序 | 创建→配置→使用→管理 |
| 按功能区域 | 功能相对独立 | 项目管理、用户管理、权限管理 |
| 按用户角色 | 不同角色使用不同功能 | 管理员操作、普通用户操作 |
| 按资源类型 | 围绕不同资源进行管理 | 工作空间管理、资源库管理、实例管理 |

### C. 截图命名规范

| 规则 | 说明 | 示例 |
|------|------|------|
| 前缀 | 模块英文缩写 | org-（组织）、inst-（实例）、repo-（资源库） |
| 功能关键词 | 截图对应的功能 | project-list、create-dialog、settings |
| 格式 | PNG | .png |
| 完整命名 | `{前缀}-{功能关键词}.png` | `org-project-list.png` |

### D. 文字说明要求

**每个章节必须满足的最低文字说明要求**：

| 章节层级 | 最低文字量 | 说明 |
|----------|------------|------|
| 一级章节（1. / 2. / ...） | ≥ 2 段 | 章节开头引言 + 功能概述 |
| 二级章节（1.1 / 2.1 / ...） | ≥ 1 段 | 说明子功能的作用和使用场景 |
| 三级章节（1.1.1 / ...） | ≥ 1 段 | 说明具体操作或概念 |

**判断标准**：如果去掉所有表格和列表后，章节内容无法让用户理解功能，则文字说明不充分。

### E. 与子模块文档的关系

**_index.md** 是模块入口文档，提供：
- 模块整体概述和架构说明
- 核心功能的简要介绍
- 指向子模块文档的导航链接

**子模块文档** 是详细说明文档，提供：
- 特定功能的深入描述
- 详细的操作步骤和配置说明
- 截图和示例

**链接关系**：
- `_index.md` → 子模块文档：在"目录"和"更多主题"章节提供链接
- 子模块文档 → `_index.md`：文档末尾提供 `[← 返回{模块名称}](./_index.md)` 链接
